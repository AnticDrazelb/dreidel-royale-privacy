# The package API surface this port depends on.
#
# Every line is a claim about a Unity package: that this member exists, on this
# type, in this namespace, at the version the manifest pins. verify.py checks each
# one against the package's real source, fetched from Unity's public mirror.
#
# It exists because four separate build failures in one evening had the same cause:
# code written against a remembered API, type-checked against a stub written from
# the same memory, so the stub agreed with the mistake. A stub cannot catch an
# author being confidently wrong; only the real source can. Anything added to the
# port that touches a package goes on this list.
#
#   format:  package | namespace | Type | member
#            member may be `.ctor` for a constructor, or omitted to check the type only
